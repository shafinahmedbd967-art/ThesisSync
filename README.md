## 🚀 Overview

**ThesisSync** is a modern, web-based platform designed to help students efficiently manage their thesis or project work. It provides a structured environment for organizing tasks, collaborating with team members, and tracking progress throughout the academic project lifecycle — replacing scattered documents and messages with one centralized workspace.

This project leverages **AI-assisted development** to accelerate implementation, while the core feature planning, system logic, and customization were defined and directed by the author.

---

## ✨ Features

- 📂 **Thesis & Project Management** — organize and track thesis/project progress in one place
- 👥 **Team Collaboration** — coordinate with group members on shared academic work
- 📝 **Task Tracking System** — break down project work into manageable, trackable tasks
- 🔐 **Authentication & User Management** — secure sign-in and user handling powered by Supabase
- ⚡ **Fast Performance** — built with Vite for instant dev feedback and optimized builds
- 🎨 **Clean, Modern UI** — styled with Tailwind CSS for a responsive, minimal interface

## ⚙️ Setup & Installation

### 1️⃣ Clone the repository
```bash
git clone https://github.com/shafinahmedbd967-art/ThesisSync.git
cd ThesisSync
```

### 2️⃣ Install dependencies
```bash
npm install
```

### 3️⃣ Environment configuration
Create a `.env` file in the root directory and add:
```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 4️⃣ Run the project
```bash
npm run dev
```

Then open in your browser:
```
http://localhost:5173
```
